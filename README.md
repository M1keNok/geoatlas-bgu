# ГеоАтлас — Номенклатура Общего Землеведения (v10.0)

Интерактивный атлас и умный тренажёр для подготовки к зачёту и лекциям по номенклатуре общего землеведения БГУ. Работает полностью автономно через `file://` (двойной клик по `index.html`), как приложение macOS (`ГеоАтлас.app`) и как Telegram Mini App.

## Ключевые возможности v10.0

- **4 модуля программы БГУ**:
  1. Береговая линия, крайние точки, цифры Земли, материки, Океания и пустыни (`module1`, включая `m1_continents_earth`)
  2. Геологическая хронология, горы (эпохи складчатости), вулканы, впадины, равнины (`module2`)
  3. Мировой океан: моря, проливы, заливы, жёлоба, тёплые и холодные течения (`module3`)
  4. Воды суши: реки (бассейны стока), водопады и озёра (`module4`)
- **2 честных уровня объёма**:
  - `⭐ Главные ориентиры` — базовые ключевые объекты программы.
  - `🎓 Вся программа БГУ` — полный список номенклатуры с мелкими объектами и теорией.
- **3 режима подготовки и единый движок**:
  - `🎓 Учить` — пространственное обучение **кластерами по 5 соседних объектов** (просмотр на карте → скрытие названий → проверка + 3D-флип-карточка).
  - `🎯 Экзамен` — слепой поиск объектов по карте с компасом на 8 румбов.
  - `⚡ Квиз` — «Узнать по точке» с 4 вариантами из ближайших географических соседей.
- **3 глубины теории**: `Только карта`, `С теорией (Рекомендуем)` и `Настроить ⚙️` (выбор типов вопросов по каждому модулю).
- **Умная самооценка (`AutoCompositeSRS`)**: после попадания на карте флип-карточка имеет только 2 кнопки (`❌ Не назвал` / `✅ Вспомнил`); при провале поиска ответ сразу показывается для запоминания, а система сама фиксирует слабые места (`🩹 Мои слабые места`).
- **📚 Конспект-шпаргалка**: табличный справочник по всем 4 модулям с поиском и кнопкой `🎯 На карте` для мгновенного перехода к объекту.
- **Офлайн-карта**: при отсутствии интернета тренажёр автоматически переключается на встроенную векторную карту (`vendor/world_vector.js`).

## Структура проекта

- `index.html` — точка входа (Zero-Build, без сборщиков и Node-зависимостей в рантайме).
- `css/01..04.css` — модульные стили (Obsidian/Emerald тема, сетка хаба, HUD карты, 3D-карточка и модальные окна).
- `js/01..08.js` — модульная архитектура (`MotionFX`, `StorageAdapter`, `GeoMath`, `MapEngine`, `LearningEngine`, `UIHub`, `UITrainer`, `UIAtlas` + `UICheatsheet`).
- `data/data_module1..4.js` — обогащённая база номенклатуры (полилинии хребтов/рек/течений, `bounds` равнин/морей/озёр, `isCoreLandmark`).
- `scripts/verify_project.js` — автотесты целостности данных, хитбоксов, кластеризации и SRS.
