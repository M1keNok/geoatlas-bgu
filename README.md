# Номенклатура ОЗ

Интерактивный атлас и система подготовки по номенклатуре общего землеведения. Работает полностью автономно через `file://` (двойной клик по `index.html`), как приложение macOS (`ГеоАтлас.app`) и как веб-приложение.

## Ключевые возможности

- **Устные карточки только там, где карта не нужна**:
  - **Модуль 1**: На карте — крайние мысы (показ точки без спойлера названия → карточка «назовите мыс»), полуострова, острова, пустыни · В карточках — материки (площади, средние высоты, рекорды), цифры Земли, Океания, типы пустынь.
  - **Модуль 2**: На карте — горы, вулканы, впадины, равнины (с вопросами складчатости/отметок после показа).
  - **Модуль 3**: На карте — моря, проливы, заливы, жёлоба, течения · В карточках — 5 целых океанов.
  - **Модуль 4**: На карте — реки, водопады, озёра.
- **Корректная геометрия через 180° меридиан**: Алеутские острова, Чукотский полуостров, Берингово море и тихоокеанские течения/жёлоба отображаются локально без растяжения на всю карту.
- **Кнопка «⏭ Пропустить» на каждой карточке**: позволяет пропустить детали, которые не требует конкретный преподаватель, без ошибок.
- **Режим «📖 Атлас»**: открывается сразу на Модуле 1 с удобным переключением между разделами и поиском.
